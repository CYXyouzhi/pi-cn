# pi-cn — Pi 中文汉化插件

把 Pi 界面变成「英文选项 + 中文注释」，面向不熟悉英文的用户。

## 功能

1. **`/` 命令补全中文说明**：输入 `/` 时每条命令显示中文注释（内置命令 + 已装插件/模板/skill 动态适配，新装的命令也会出现，未翻译的显示英文兜底）。
2. **使用频率排序**：常用命令自动排前面（补全选中或手动输入都会累计次数），没用过的按字母序。
3. **界面文本自动汉化**：`/model`、`/thinking`、`/settings`、`/tree`、`/resume`、`/trust`、启动横幅/更新提示等主程序界面，以及 `/plan`（计划模式）、`/goal`（目标）、`/btw`（侧线程）三个插件的菜单/设置/状态界面，说明文字自动变中文（英文选项保留 + 括号注释）；选项英文名与功能不变。插件加载时自动检测并应用，升级 Pi 后自动恢复（升级后重启两次生效）。
4. **管理命令（单一入口）**：`/汉化`（交互菜单：自动汉化/扫描/补充命令/界面管理）、`/汉化 自动`（扫描+调用当前模型翻译+自动应用，新装插件也能自动获得中文注释）、`/汉化 扫描`（列出界面未汉化的英文文本）、`/汉化 命令`（补充命令中文说明）、`/汉化 界面 [状态|应用|清空频率]`（界面补丁管理）。

## 安装

```bash
pi install ./pi-cn          # 本地安装（本目录）
pi install npm:pi-cn        # 发布到 npm 后
pi install git:github.com/your-name/pi-cn@v1   # 发布到 GitHub 后
```

安装后重启 Pi（或 `/reload`）。

## 安全原则

- 只改**用户可见界面文字**；给 AI 看的内容（系统提示、工具描述、SKILL.md、MCP 工具定义）一律不动。
- 界面汉化是给 Pi 主程序打补丁（Pi 无官方 i18n 接口），每次应用前自动备份 `.bak`、应用后语法校验、失败自动还原。卸载插件不会自动还原已修改的文件，如需彻底还原可手动删除各文件的 `.bak` 覆盖或重装 Pi/插件。
- 补全汉化是纯提示层接管，不改变任何命令执行；非 `/` 场景（`@` 文件补全等）完全委托原逻辑。

## 用户数据

- 翻译表：`~/.pi/agent/commands-cn.json`（新增命令的中文说明，可手动编辑）
- 使用频率：`~/.pi/agent/commands-frequency.json`（`/汉化 界面 清空频率` 可重置）
- 自动汉化映射：`~/.pi/agent/hanhua-auto.json`（`/汉化 自动` 生成的动态映射，升级后自动重新应用）
- 自定义 Pi 路径（非默认安装时）：在 `~/.pi/agent/pi-cn.json` 写 `{ "piDist": "/path/to/pi/dist" }`

## 发布指引

```bash
cd pi-cn
# 发布到 npm
npm publish
# 或发布到 GitHub（先把仓库推到 GitHub，再打 tag）
git tag v1.0.0 && git push --tags
```

用户安装后，升级 Pi 或新装插件时：
- Pi 升级 → 插件下次加载自动重新应用界面汉化（重启两次生效）
- 新装插件 → `/` 补全说明自动出现（英文兜底）；其界面文字可用 `/汉化界面` 查看，或联系维护者补充映射
