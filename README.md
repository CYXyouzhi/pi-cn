# pi-cn — Pi 中文汉化插件

把 Pi 界面变成「**英文选项 + 中文注释**」：功能名保留英文（便于对照文档、搜索报错），说明文字全部变中文。面向看得懂英文命令但读界面说明吃力的用户。

```
Auto-apply patches（自动应用补丁）        ← 长这样
Fix（修复）  Skip（跳过）  Abort（中止）
```

## 功能

### 1. `/` 命令补全中文说明

输入 `/` 时，每条命令右侧显示中文注释。内置命令 + 已装插件 / 提示模板 / skill **动态适配**——新装的命令也会出现，未翻译的显示英文兜底，不会漏。

### 2. 使用频率排序

常用命令自动排前面（补全里选中或手动输入都会累计次数），没用过的按字母序。装得越多越省事。

### 3. 界面文本自动汉化

覆盖范围：

| 目标 | 内容 |
|---|---|
| Pi 主程序 | `/model`、`/thinking`、`/settings`、`/tree`、`/resume`、`/trust`、启动横幅、更新提示等 |
| `/plan` | 计划模式菜单、状态栏、TUI 组件 |
| `/goal` | 目标模式菜单与设置 |
| `/btw` | 侧线程界面 |
| pi-ui | 通用 UI 组件文本 |

插件加载时自动检测并应用，**Pi 升级后自动重新应用**（升级后重启两次生效）。

### 4. `/汉化` 管理命令

单一入口，无参数时弹交互菜单。

| 命令 | 作用 |
|---|---|
| `/汉化` | 交互菜单（自动汉化 / 清除 / 频率 / 体检） |
| `/汉化 自动` | 体检 + 扫描 + 调用当前模型翻译 + 应用（新装插件也能自动获得中文） |
| `/汉化 扫描` | 列出尚未汉化的界面文本（已排除给 AI 看的内容） |
| `/汉化 体检` | **映射体检**，见下 |
| `/汉化 清除` | 从 `.bak` 还原所有汉化，恢复英文原版 |
| `/汉化 频率` | 清空使用频率统计 |
| `/汉化 命令` | 手动补充命令的中文说明 |
| `/汉化界面 [状态\|应用\|清空频率]` | 界面补丁的底层管理 |

#### `/汉化 体检` 是干什么的

汉化的本质是对源码做「文本层手术」（`src.split(英文).join(中文)`），这会带来三类隐患，体检会把它们挑出来：

| 类型 | 含义 |
|---|---|
| `compare` | 该字符串同时用于显示和逻辑比较，替换后判断可能永假（**最高危**） |
| `identifier` | 短 key 误伤「以它开头的其他文案」，如 `Unknown error` 命中 `Unknown error occurred` |
| `stale` | Pi 升级改了文案，旧 key 失效，汉化静默丢失（无害但要知道） |
| `duplicate` | 同一 key 在多张表里重复 |

`/汉化 自动` 和插件启动时都会自动跑一次，发现 `compare` 级别的风险会提示你先体检。

## 安装

```bash
pi install npm:pi-cn                              # 从 npm（推荐）
pi install git:github.com/CYXyouzhi/pi-cn         # 从 GitHub
pi install ./pi-cn                                # 本地目录
```

装完重启 Pi（或 `/reload`）。

## 安全原则

- **只改用户可见的界面文字**。给 AI 看的内容——系统提示、工具描述、`SKILL.md`、MCP 工具定义——**一律不动**。
- 界面汉化是给 Pi 主程序打补丁（Pi 没有官方 i18n 接口）。每次应用前**自动备份 `.bak`**，应用后**语法校验**，失败**自动还原**。
- 补全汉化是纯提示层接管，**不改变任何命令的执行**；非 `/` 场景（`@` 文件补全等）完全委托原逻辑。
- 卸载插件**不会**自动还原已修改的文件。要彻底还原用 `/汉化 清除`，或手动用 `.bak` 覆盖回去。

## 用户数据

| 文件 | 用途 |
|---|---|
| `~/.pi/agent/commands-cn.json` | 命令的中文说明（可手动编辑） |
| `~/.pi/agent/commands-frequency.json` | 使用频率（`/汉化 频率` 重置） |
| `~/.pi/agent/hanhua-auto.json` | `/汉化 自动` 生成的动态映射，升级后自动重新应用 |
| `~/.pi/agent/pi-cn.json` | Pi 装在非默认路径时写 `{ "piDist": "/path/to/pi/dist" }` |

## 已知限制

- Pi 主程序**更新后**仍需重启两次才能让界面汉化生效（第一次加载检测到变更，第二次应用）。
- `stale` 类问题（插件更新导致旧 key 失效）不修——它们无害，只是映射表里已经用不到的条目。
- 少数动态拼接的模板串（如 `` `Could not refresh ${...}` ``）覆盖不全，只在边缘路径出现。

## 开发与发布

```bash
# 发布到 npm（需要 npm 登录，且能访问 registry.npmjs.org）
npm publish

# 或走 GitHub Actions：把 version 递进后打 tag 推送
git tag v0.2.1 && git push origin v0.2.1
```

带 `pi-package` 关键词的 npm 包会被 [Pi 官方插件市场](https://pi.dev/packages) 自动收录，无需单独提交。
